## Question

What are the standard features and quality-of-life improvements of an employee leave management system, and which should be included in a college-grade secure web application? Research core actions (request, approval/reject, balance tracking), role management (employee / manager / admin), dashboard/reporting, notifications/status tracking, and any UX improvements that make it intuitive and easy to use. Report findings with rationale for each feature's value and whether it fits a simple Flask/SQLite implementation.
