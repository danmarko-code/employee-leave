## Question

How should the UI be built given the user wants a non-generic, polished design?

## Resolution

Two-phase approach: (1) Layout/structure first — proper grids, alignments, screen inventory, navigation, UX flow, without styling focus; (2) Styled redesign after functionality works, using frontend-design skill for polished non-template look. Design references allowed but code must be modular.
